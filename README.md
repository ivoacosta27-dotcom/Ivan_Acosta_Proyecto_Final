# Maoui Fragance - Sistema de Gestión de Usuarios
Trabajo Práctico Final de Informática 4.° año · Instituto Sagrado Corazón de Almagro

## Requisitos
- XAMPP (Apache y MySQL)
- Visual Studio Code
- Navegador web moderno

## Instrucciones de Instalación
1. Clonar o copiar la carpeta `maoui-fragance` dentro de `C:\xampp\htdocs\`.
2. Iniciar Apache y MySQL desde el panel de control de XAMPP.
3. Crear la base de datos ejecutando el script `sql/base_de_datos.sql` en phpMyAdmin.
4. Ejecutar por única vez `crear_admin.php` para generar el usuario administrador.
5. Acceder al sistema desde el navegador en: `http://localhost/maoui-fragance/index.php`
